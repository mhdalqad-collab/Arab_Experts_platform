# الحزمة AD — الأسرار ومفاتيح التشفير والشهادات الرقمية V101

تحكم الحزمة البيانات الوصفية للأسرار ومفاتيح التوقيع والتشفير والشهادات، وتربطها بالأصل التقني والمالك والأمين وسياسة التدوير. ولا تخزن قاعدة البيانات كلمة مرور أو رمزًا أو مفتاحًا خاصًا؛ بل تحفظ مرجعًا إلى خزنة أسرار أو KMS معتمدة وبصمة تحقق فقط.

تسجل روابط استخدام السر وفق أقل صلاحية، وتفصل منفذ التدوير عن المتحقق منه، وتلزم التحقق من الأصول التابعة قبل اعتماد النجاح. كما تحفظ مخزون الشهادات ومددها وجهة الإصدار وبصمتها ومسؤول التجديد.

لا يُجدّد السر أو المفتاح تلقائيًا بقرار قاعدة البيانات، ولا تعد عملية التدوير ناجحة دون موافقة وأدلة وتحقق مستقل. والقيم السرية نفسها لا تظهر في السجل أو التقارير أو أحداث التدقيق.

## مخرجات الحزمة

- سياسات عمر وتدوير واستجابة طارئة.
- سجل وصفي للأسرار دون قيمها الحساسة.
- ربط الاستهلاك بالأصول والغرض والبيئة.
- أحداث تدوير محكومة بأدلة ومراجعة مستقلة.
- مخزون شهادات ومواعيد انتهاء وتجديد.
- منظور للانتهاء والتدوير ومراجعة أقل صلاحية.
- تراجع آمن يحمي أدلة التدوير والشهادات.
