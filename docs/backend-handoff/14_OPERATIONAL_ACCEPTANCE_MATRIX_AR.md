# مصفوفة القبول التشغيلي

| المجال | دليل القبول | المسؤول | الحالة الأولية |
|---|---|---|---|
| CI | Workflow أخضر على Commit الإصدار | قائد التطوير | معلق خارجيًا |
| الحاويات | Digest لكل صورة وHealth Check ناجح | DevOps | معلق خارجيًا |
| PostgreSQL | 93 ترحيلًا واختبارات SQL ناجحة | DBA | معلق خارجيًا |
| Backup/Restore | تقرير استعادة على قاعدة فارغة | DBA | معلق خارجيًا |
| OIDC | تسجيل ودخول ورفض Token الخاطئ وتدوير JWKS | الأمن/الهوية | معلق خارجيًا |
| RBAC/Step-up | نتائج إيجابية وسلبية لكل Permission حساس | الأمن/UAT | معلق خارجيًا |
| الملفات | رفع وفحص ومنح وتنزيل وانتهاء صلاحية | Backend/الأمن | معلق خارجيًا |
| الإشعارات | نجاح وفشل مؤقت وDead-letter واسترداد | التشغيل | معلق خارجيًا |
| الأداء | حمل متفق عليه دون تجاوز SLO | الأداء | معلق خارجيًا |
| المراقبة | Logs وMetrics وAlerts وRedaction | SRE | معلق خارجيًا |
| TLS/DNS | شهادة صالحة وتوجيه خارجي آمن | البنية التحتية | معلق خارجيًا |
| UAT | توقيع أصحاب المصلحة | مالك المنتج | معلق خارجيًا |

تبقى الحالة **NO-GO** حتى تتحول جميع البنود الحرجة إلى «ناجح» مع رابط دليل.
