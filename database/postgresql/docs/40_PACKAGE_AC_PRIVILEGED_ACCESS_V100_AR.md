# الحزمة AC — الوصول المميز المؤقت ومراجعة الجلسات V100

تحوّل الحزمة الصلاحيات الحساسة من منح دائم إلى طلب محدد الأصل والصلاحية والغرض والفترة، مرتبط بموافقة محكومة وتحقق إضافي من الهوية. وتبقى أدوار RBAC والتفويضات ومراجعات الوصول الحالية كما هي دون استبدال.

تسجل جلسة الوصول المميز ومصدرها وبصمة الجهاز وتسلسل أحداثها وبصمات سجل الأوامر، ثم تلزم مراجعة مستقلة بعد انتهاء الجلسة. ويمكن تحويل الاستثناء إلى قضية تدقيق مرتبطة بدل إغلاقه داخل سجل الجلسة.

لا يُمنح الوصول المميز لمجرد امتلاك دور إداري، ولا تمدد الصلاحية تلقائيًا، ولا تعتبر الجلسة مكتملة دون سجل ثابت ومراجعة لاحقة. ويظل التنفيذ الفعلي مشروطًا بموصل هوية آمن خارج قاعدة البيانات.

## مخرجات الحزمة

- طلب وصول مميز مرتبط بالأصل والصلاحية والموافقة.
- منح مؤقت بحدود نطاق وتحقق إضافي.
- جلسات موثقة قابلة للإيقاف والانتهاء الآلي.
- أحداث متسلسلة ذات بصمات مانعة للعبث.
- مراجعة مستقلة وربط بقضايا التدقيق.
- منظور يكشف انتهاء المنح والجلسات غير المراجعة.
- تراجع آمن يرفض إزالة أدلة الجلسات.
