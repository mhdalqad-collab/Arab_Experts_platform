# معايير قبول PostgreSQL V6

- تنفذ 23 ترحيلًا و7 بذور على PostgreSQL 16 دون خطأ.
- يوجد 249 بلدًا وأنواع العضوية السبعة دون تكرار.
- لا ينشأ Party أو Account مكرر عند إعادة المحاولة.
- لا يستطيع مقدم الاعتماد اعتماد طلبه.
- يمنع جمع صلاحيات SOD المتعارضة دون استثناء معتمد.
- لا يقبل تعديل أو حذف أحداث التدقيق.
- يحتفظ سحب الموافقة بتاريخها ولا يمحو السجل السابق.
- لا يظهر حقل عام إذا كانت تفضيلات الخصوصية تمنعه.
- لا يحفظ سر تكامل كنص؛ يحفظ مرجع Secret Manager فقط.
- تعالج رسالة Inbox الخارجية مرة واحدة.
- لا ينشئ تعديل منشور فوق النسخة المنشورة؛ ينشئ إصدارًا جديدًا.
- يمكن ربط البحث والمنشورات والفعاليات والأصول بعقد التصنيف.
- تعمل الاستعلامات الأساسية ضمن أهداف الأداء بعد `EXPLAIN ANALYZE`.
- تنجح استعادة نسخة احتياطية في تجربة موثقة.
- يستطيع التطبيق السابق العمل عند تعطيل ميزات V6.
