# الحزمة AF — كتالوج البيانات والنَّسب وتحليل الأثر V103

تضيف الحزمة قاموسًا مؤسسيًا للمصطلحات وكتالوجًا للحقول يربط المعنى التجاري بالتعريف التقني وتصنيف الحساسية والمصدر المعتمد. ثم تمثل مسار البيانات بعقد وروابط موثقة من المصدر، عبر التحويلات، إلى واجهات البحث وميزات المطابقة والتقارير والتصدير.

لكل تحويل مرجع وإصدار عقد وبصمة تحقق، ولكل تغيير مؤثر تقييم يبين أثره على البحث والمطابقة والخصوصية وخطة تخفيفه. ويفصل النموذج بين من أعد تقييم الأثر ومن اعتمده.

لا تمنح قاعدة البيانات الموافقة على تغيير مخطط أو معنى تلقائيًا، ولا تنشئ نسبًا تقديريًا غير مثبت. ولا يعتمد تغيير مؤثر على البحث أو المطابقة أو الخصوصية قبل تقييم واعتماد مستقل موثق.

## مخرجات الحزمة

- قاموس مصطلحات عربي/إنجليزي محكوم.
- كتالوج حقول ومصادر وتصنيفات.
- عقد نسب للمصادر والتحويلات والاستخدامات.
- روابط متحققة ببصمات وإصدارات عقود البيانات.
- تقييم أثر على البحث والمطابقة والخصوصية.
- منظور يكشف عناصر البيانات غير القابلة للتتبع.
- تراجع آمن يحمي أدلة النسب والتقييمات المعتمدة.
