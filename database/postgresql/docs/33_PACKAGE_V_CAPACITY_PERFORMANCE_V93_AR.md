# الحزمة V — إدارة السعة والأداء والتوسع V93

تثبت الحزمة خطة سعة لكل نطاق خدمة، مع أفق التخطيط ومعدل النمو المتوقع ومعامل الذروة والهامش الأدنى المطلوب. وتسجل القياسات الخام وحدودها اللينة والصلبة دون استبدال التاريخ.

تدعم اختبارات الحمل الأساسية والضغط والارتفاع المفاجئ والاستمرارية الطويلة والتحويل، وتوثق زمن P95 ومعدل الأخطاء والاختناق والأدلة. كما تضبط سياسات التوسع اليدوي والمجدول والآلي وحدود التوسع وفترة التهدئة.

لا تمنح بوابة السعة حالة `READY` إلا لخطة نشطة وحديثة، واختبار حمل ناجح، وهامش موارد كافٍ. وهي تعيد قرارًا قابلًا للتدقيق ولا توسع الموارد أو تنشر إصدارًا تلقائيًا.
