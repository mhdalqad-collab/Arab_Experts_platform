# الحزمة AK — التعدد اللغوي والتوطين وإتاحة الوصول V108

تحول هذه الحزمة اللغة وإتاحة الوصول من خصائص شكلية في الواجهة إلى مكونات محكومة وقابلة للاختبار. وتدعم اللغة والدولة واتجاه الكتابة والتقويم والعملة وصيغ الأرقام والتواريخ، مع سلسلة رجوع واضحة عند غياب ترجمة.

## القواعد

- تعريف اللغة لا يساوي تعريف البيئة المحلية؛ فالبيئة تشمل الدولة والاتجاه والتقويم والعملة والتنسيقات.
- كل نص واجهة أو تحقق أو إشعار أو محتوى قانوني يمتلك مفتاحًا ثابتًا وسياقًا ومتغيرات معلنة.
- تحفظ الترجمة بإصدارات وبصمة للنص المصدر، فتتحول إلى «قديمة» إذا تغير المصدر.
- تميز الترجمة البشرية والآلية والمراجعة المهنية، ولا تنشر الترجمة الآلية غير المراجعة في المحتوى الحساس.
- لا يراجع المترجم عمله عندما تكون المراجعة مطلوبة.
- المحتوى المهني والتدريبي يحتفظ بترجمة لكل حقل دون نسخ الكيان كاملًا.
- متطلبات الإتاحة ترتبط بمعيار ومستوى خطورة ونطاق تطبيق.
- تجمع الاختبارات الآلية واليدوية وتقنيات المساعدة واختبار المستخدم؛ ولا يعد الاختبار الآلي وحده إثباتًا كاملًا.
- تحفظ أدلة الاختبار والمعالجة والتحقق المستقل.

## بوابة الإصدار

يفحص المنظور `localization.v_localization_release_readiness` وجود الترجمات الإلزامية المعتمدة، ثم يمنع جاهزية البيئة المحلية إذا بقي إخفاق عالي أو حرج في إتاحة الوصول بلا تحقق بعد المعالجة.

## التراجع

يرفض التراجع عند وجود ترجمات معتمدة أو محتوى محلي منشور أو أدلة إتاحة وصول، حمايةً للتاريخ التحريري وحقوق المستخدمين.
