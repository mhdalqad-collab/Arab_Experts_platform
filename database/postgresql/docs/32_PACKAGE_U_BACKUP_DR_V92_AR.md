# الحزمة U — النسخ الاحتياطي والتعافي واستمرارية الأعمال V92

تثبت الحزمة خطة استمرارية لكل خدمة حرجة، مع RPO وRTO وخطط النسخ والتحويل والعودة والتواصل. وتسجل كل عملية نسخ دون استبدال تاريخها، بما يشمل نقطة الاستعادة والبصمة والتشفير وفترة عدم القابلية للتغيير.

لا تعتبر الخطة جاهزة لمجرد وجود نسخة احتياطية؛ يلزم تمرين استعادة ناجح، والتحقق من سلامة البيانات، وتحقيق RPO وRTO، وعدم تأخر مراجعة الخطة. بوابة التحويل إلى البيئة البديلة تعيد قرارًا صريحًا ومسببًا ولا تنفذ التحويل آليًا.

## معايير القبول

- لا تمنح حالة `READY` دون تمرين ناجح ودليل سلامة بيانات.
- يجب ألا يتجاوز RPO وRTO المحققان الحدود المعتمدة.
- تحتفظ كل نسخة ونتيجة اختبار بتاريخها ولا تستبدل السجل السابق.
- يرفض التراجع إذا وُجدت أدلة استمرارية فعلية.
