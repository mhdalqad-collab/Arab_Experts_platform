# نموذج التهديدات الأساسي — EIM V113 R5

| الأصل/الحد | التهديد الأهم | الضبط الموجود | دليل الاختبار المطلوب على السيرفر |
|---|---|---|---|
| OIDC والجلسة | انتحال الهوية أو Token غير صالح | تحقق التوقيع والمصدر والجمهور والانتهاء | اختبارات مزود الهوية الحقيقي وتدوير المفاتيح |
| العمليات الحساسة | تجاوز الدور أو ضعف المصادقة | Permissions وStep-up وفصل الواجبات | مصفوفة أدوار واختبارات سلبية لكل دور |
| PostgreSQL | وصول زائد أو تعديل غير مصرح | شبكة داخلية وترحيلات منفصلة | مستخدم Runtime محدود ومراجعة GRANT |
| الملفات | رفع ضار أو تنزيل غير مصرح | أنواع محددة، SHA-256، فحص، منح مؤقت | اختبار Scanner وObject Storage وروابط الانتهاء |
| `/internal/` | تزوير Callback | Tokens داخلية ورفضها في Nginx | اختبار من الإنترنت ومن الشبكة الخاصة |
| API | إساءة استخدام أو إغراق | حدود أحجام وRate limiting وTimeouts | اختبار حمل وضبط الحدود حسب SLO |
| الأسرار | تسرب مفتاح أو Token | نماذج بلا أسرار وفحص أنماط وPreflight | Secret Manager وتدوير موثق |
| سلسلة التوريد | اعتماد ضعيف أو صورة معدلة | Lockfile وAudit وSBOM وCI | توقيع الصور وسياسة Registry |
| السجلات | فقد التتبع أو كشف بيانات | Correlation ID وعدم التخزين المؤقت | مراجعة Redaction وRetention والتنبيهات |
| الترحيلات | فقد أو تعارض البيانات | Backup وRollback وسياسة ترحيل | Restore rehearsal وقياس مدة الترحيل |

يُراجع هذا النموذج بعد ربط مزودي OIDC والتخزين والإشعارات، وبعد أي تغيير معماري أو حادث أمني.
