# قائمة قرار الإنتاج Go/No-Go — V113 R5

لا يُعتمد قرار **GO** إلا إذا كانت جميع البنود الحرجة ناجحة ومثبتة بدليل.

## بوابات حرجة

- [ ] CI أخضر على Commit الإصدار نفسه.
- [ ] صور Docker مبنية من Commit محدد وموسومة وغير قابلة للاستبدال.
- [ ] `npm audit --omit=dev --audit-level=high` ناجح أو الاستثناءات معتمدة.
- [ ] SBOM محفوظ مع الإصدار.
- [ ] Preflight ناجح دون قيم توضيحية.
- [ ] Backup قبل الترحيل محفوظ خارج الخادم ومطابق للبصمة.
- [ ] Restore rehearsal ناجح على قاعدة فارغة.
- [ ] الترحيلات 93/93 ناجحة على نسخة مماثلة للإنتاج.
- [ ] Rollback أو Forward-fix لكل تغيير حرج متفق عليه.
- [ ] OIDC وStep-up والصلاحيات مختبرة.
- [ ] Object Storage والفحص الأمني للملفات مختبران.
- [ ] Smoke Tests ناجحة.
- [ ] UAT موقع من ممثلي الأعمال.
- [ ] DNS وTLS والمراقبة والتنبيهات جاهزة.
- [ ] فريق الدعم والمناوبة وخطة الحوادث معتمدة.

## قرار NO-GO تلقائي

- فشل Ready Health Check أو اتصال PostgreSQL.
- فشل ترحيل أو اختلاف غير مفسر في المخطط.
- سر إنتاجي داخل المصدر أو الحزمة.
- ثغرة عالية غير مقبولة في اعتماديات الإنتاج.
- عدم وجود Backup صالح أو فشل تجربة الاستعادة.
- تعطل OIDC أو تجاوز الصلاحيات أو فشل Step-up.
- كشف `/internal/` خارج الشبكة الموثوقة.
- فشل رحلة تسجيل أو رفع ملف أو طلب عضوية حرجة.
