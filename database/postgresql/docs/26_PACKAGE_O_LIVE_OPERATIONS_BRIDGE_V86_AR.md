# الحزمة O — تفعيل جسر العمليات V86

## الغرض

تحويل مركز التشغيل من شاشة قراءة فقط إلى واجهة قادرة على إرسال أوامر محكومة، مع بقاء الأزرار معطلة افتراضيًا حتى تكتمل طبقات الثقة في بيئة التشغيل.

## شروط التفعيل الثلاثة

1. نجاح الاتصال بمحول PostgreSQL الموثوق.
2. إعلان المحول أن تنفيذ الأوامر متاح وأن التحقق الإضافي جاهز.
3. تفعيل علمي البيئة `POSTGRES_OPERATIONS_ACTIONS_ENABLED` و`POSTGRES_OPERATIONS_STEP_UP_READY` صراحة.

غياب أي شرط يبقي الواجهة للقراءة فقط، ولا يمكن للمتصفح تجاوز ذلك لأن نقطة API تعيد الفحص قبل تمرير الأمر.

## تجربة المشغل

- اختيار أحد الأوامر الأربعة من مركز التشغيل.
- ظهور نافذة تأكيد توضح حساسية الإجراء.
- إدخال سبب لا يقل عن ثمانية أحرف.
- تحديد نسبة مستهدفة عند طلب مراجعة الترقية.
- توليد مفتاح مستقل لمنع تكرار التنفيذ.
- إعادة تحميل مؤشرات التشغيل بعد نجاح الأمر.

## الأمان والحوكمة

- لا تُرسل أسرار المحول إلى المتصفح.
- تفحص نقطة API دور مدير المنصة مرة أخرى.
- القائمة البيضاء تمنع تمرير أوامر غير معروفة.
- الترقية «طلب مراجعة» وليست تفعيلًا مباشرًا.
- قاعدة PostgreSQL هي السلطة النهائية للتحقق من الدور والتكرار والحالة.
- عند فشل التنفيذ تعرض الواجهة رسالة محافظة ولا تدعي تغير الحالة.

## ما يلزم في بيئة الإنتاج

توفير محول مستقل متصل بقاعدة PostgreSQL، وربطه بمزود هوية يدعم تحققًا إضافيًا حديثًا، ثم ضبط المتغيرات الأربعة الخاصة بعنوان المحول ورمزه وتفعيل الأوامر وجاهزية التحقق. لا تُفعل الأعلام قبل اجتياز اختبار فصل الواجبات وسجل التدقيق.
