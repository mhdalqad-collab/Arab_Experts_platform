# EIM-MVP-004 — الحزمة الثالثة: البحث والتصنيف والتدريب

**الإصدار:** V113  
**المتطلبات المالكة:** MVP-SRC-001..006 وMVP-TRN-001..007  
**المسارات:** J01 وJ05 وJ11  
**الحالة:** تصميم تفصيلي مكتمل؛ الفهرسة والخدمات الحية وUAT لاحقة.

## 1. هدف الحزمة

تغلق هذه الحزمة العلاقة بين التصنيف المهني والتدريبي، البحث العام والمتخصص، الدورة والحقيبة والإصدار والطرح، والمركز والمدرب ومالك المحتوى. وتضمن أن نتائج البحث قابلة للفرز والمقارنة واتخاذ القرار، وأن منع الازدواج يحمي الكتالوج دون أن يمنع الابتكار أو الإصدارات المشروعة.

## 2. النموذج المفاهيمي المتكامل

```text
ConceptScheme
  └─ MainDomain
      └─ Specialty
          └─ WorkPractice
              └─ DetailedContent

Course ──classified by──> Concept[*]
Course ──has──> CourseVersion[1..n]
CourseVersion ──uses──> ContentPackage[0..n]
CourseVersion ──offered as──> CourseOffering[0..n]
CourseOffering ──delivered by──> TrainerAssignment[1..n]
CourseOffering ──provided by──> TrainingCenter[0..1]
Course/ContentPackage ──governed by──> RightsBundle + License
```

### حدود الكيانات

| الكيان | ماذا يمثل | لا يمثل |
|---|---|---|
| Course | هوية المنتج التعليمي المستقرة | موعدًا أو سعرًا أو ملف حقيبة |
| CourseVersion | نسخة أهداف ومحتوى ومتطلبات الدورة | طرحًا متاحًا للتسجيل |
| ContentPackage | مواد الحقيبة ومكوناتها وحقوقها | الدورة كلها أو ملكية المدرب تلقائيًا |
| CourseOffering | تنفيذ محدد بوقت ونمط ومكان وسعر وسعة | تعريف الدورة العام |
| TrainerAssignment | إسناد مدرب لطرح ودور وفترة | عضوية المدرب أو ملفه |
| TrainingCenter | مقدم/منظم محتمل للطرح | مالك المحتوى تلقائيًا |
| Enrollment | تسجيل متعلم في طرح | شراء الدورة العامة |
| Credential | إثبات نتيجة تعلم مستوفاة | مجرد حضور أو دفع |

## 3. بنية التصنيف 7×7×7

المسار المعتمد للموقع والنماذج والبحث:

`المجال الرئيسي → التخصص → نوع الأعمال والممارسات → المحتوى والممارسات التفصيلية`

### قواعد البنية

1. كل مستوى يحمل معرفًا ثابتًا ورمزًا واسمًا عربيًا وإنجليزيًا وإصدارًا وحالة.
2. لا تخزن الاختيارات كنص حر عندما يوجد مفهوم معتمد.
3. لا يعرض المستوى التالي إلا أبناء الاختيار السابق ضمن إصدار واحد.
4. يمكن للكيان الارتباط بأكثر من مسار، مع تحديد مسار أساسي ومسارات مساندة.
5. لا يعني الرقم 7 حظر التطور؛ هو بنية الإصدار المعتمد، وأي تغيير يمر بحوكمة وإصدار جديد.
6. المفهوم المتقاعد لا يحذف؛ يربط ببديل أو أكثر مع نوع العلاقة وتاريخ السريان.
7. تحفظ نتائج البحث والمطابقة مرجع إصدار التصنيف المستخدم.

### ربط التصنيف المهني والتدريبي

| المصدر | الهدف | نوع العلاقة | مثال الاستخدام |
|---|---|---|---|
| تخصص مهني | مجال تدريبي | exact/close/broader/narrower/related | توسيع البحث عن دورات تسد فجوة مهنية |
| ممارسة مهنية | مخرج تعلم | enables/requires/develops | تفسير كيف تطور الدورة ممارسة معينة |
| محتوى تفصيلي | موضوع دورة | exact/related | تحسين الدقة ومنع التطابق بالاسم فقط |
| مستوى خبرة | مستوى دورة | prerequisite/recommended | استبعاد طرح غير مناسب للمستفيد |

الربط دلالي مفسر وله ثقة ومراجع واعتماد بشري؛ لا يغير أصل أي تصنيف.

## 4. قوائم التدريب المرجعية

### اللغات

`العربية، الإنجليزية، الفرنسية، الألمانية، الإسبانية، الصينية، الهندية`

يسمح بأكثر من لغة للدورة أو المدرب، لكن كل طرح يحدد لغة تقديم أساسية ولغات دعم إن وجدت.

### مستوى الدورة

`تأسيسي، متوسط، متقدم، تخصصي، قيادي، تحضيري لشهادة مهنية`

لا يستخدم «مستوى الجمهور» بديلًا عن مستوى الدورة. ويمكن تعريف جمهور مستهدف منفصل عن المستوى.

### نمط التقديم

`حضوري، عن بعد، هجين`

### حالة الدورة والإصدار والطرح

| الكيان | الحالات الأساسية |
|---|---|
| Course | Draft, Active, Suspended, Retired, Merged |
| CourseVersion | Draft, InReview, Approved, Published, Superseded, Withdrawn |
| ContentPackage | Draft, Approved, Licensed, Restricted, Expired, Archived |
| CourseOffering | Draft, Scheduled, Published, Open, Full, Closed, Completed, Cancelled |
| Enrollment | Pending, Reserved, Confirmed, Waitlisted, Cancelled, Attended, Completed, Failed, Refunded |

## 5. دورة إنشاء دورة جديدة

```text
من داخل الحساب أو صفحة البحث
→ تحقق من العضوية والصلاحية
→ اختيار 7×7×7
→ إدخال اسم عربي/إنجليزي وأهداف ومخرجات ومستوى وجمهور
→ فحص التشابه والازدواج
→ اختيار: ربط بموجود | إنشاء إصدار | إنشاء دورة مستقلة مع سبب
→ تحديد المالك والمؤلف والحقوق
→ ربط مركز و/أو مدرب
→ حفظ المسودة
→ مراجعة واعتماد
→ نشر CourseVersion
→ إنشاء CourseOffering منفصل عند توفر موعد/نمط/سعر
```

### قواعد الوصول

- العضو المسجل ينشئ الدورة داخل حسابه ولا يعاد إلى بيانات العضوية.
- الزائر الذي يضغط «إنشاء دورة تدريبية» يمر بالدخول/التسجيل ثم يعود إلى سياق الإنشاء.
- المدرب يستطيع إنشاء دورة ونسبها إليه، أو ربط مركز مخول.
- المركز يستطيع إنشاء دورة وربط مدرب عضو في الشبكة؛ إن لم يوجد يترك الربط فارغًا.
- الإسناد لا ينقل ملكية المحتوى، والملكية لا تمنح حق التقديم دون ترخيص.

## 6. منع ازدواجية الدورات

### 6.1 الإشارات المستخدمة

| الإشارة | الوظيفة | ملاحظة |
|---|---|---|
| الاسم المطبع عربيًا وإنجليزيًا | اكتشاف التطابق والتهجئات | لا يكفي وحده للمنع |
| مسار 7×7×7 | تحديد الموضوع والممارسة | إشارة جوهرية |
| الأهداف ومخرجات التعلم | مقارنة المقصود الفعلي | أهم من الكلمات التسويقية |
| المستوى والجمهور | تمييز النسخ | قد يبرر دورة مستقلة |
| المدة ونطاق المحتوى | تمييز العمق | ليس حاسمًا وحده |
| المالك/المؤلف وحقوق المحتوى | منع الاستنساخ غير المشروع | يحتاج تحقق حقوق |
| اعتماد أو شهادة مستهدفة | تحديد المنتج | قد يستلزم إصدارًا مستقلًا |

### 6.2 قرار التشابه

| النتيجة | المعنى | الإجراء |
|---|---|---|
| Exact | نفس الهوية والمحتوى المرجعي | فتح الدورة الموجودة ومنع النسخة |
| VersionCandidate | نفس الدورة مع تعديل جوهري أو تحديث | إنشاء CourseVersion |
| Related | موضوع قريب لكن أهداف/جمهور/مالك مختلف مشروعًا | السماح مع ربط related |
| SuspectedDuplicate | تشابه مرتفع مع تعارض ملكية أو بيانات ناقصة | تعليق للنظر البشري |
| Distinct | اختلاف مبرر | إنشاء Course جديدة |

### قواعد القرار

1. يعرض النظام جدول المرشحين قبل الحفظ النهائي.
2. يوضح سبب التشابه على مستوى الاسم والتصنيف والمخرجات والحقوق.
3. لا تمنع درجة آلية الإنشاء نهائيًا إلا في التطابق التقني المؤكد وإعادة المحاولة.
4. القرار البشري المسموح: ربط، إصدار، مستقل، دمج، أو تصعيد حقوق.
5. يسجل القرار والسبب والمراجع والمستخدم والإصدار.
6. الدمج يحافظ على المعرفات القديمة والتحويلات والتسجيلات والتقييمات.

## 7. إدارة الإصدارات

### تغييرات ثانوية داخل الإصدار

- تصحيح لغوي لا يغير المعنى.
- تحديث رابط أو بيانات وصفية غير مؤثرة.
- إصلاح خطأ عرض.

### إصدار فرعي جديد

- تحديث أمثلة أو مراجع أو ترتيب المحتوى.
- تعديل مدة محدود لا يغير المخرجات الأساسية.
- تحديث مواد مع بقاء مستوى ومتطلبات الدورة.

### إصدار رئيسي جديد

- تغيير مخرجات التعلم أو المتطلبات السابقة.
- تغيير مستوى الدورة أو الجمهور جذريًا.
- تغيير نطاق 7×7×7 الأساسي.
- تغيير جوهري في المحتوى أو الاعتماد المستهدف.

الطرح يثبت `course_version_id`؛ ولا يتغير محتوى طرح بدأ التسجيل فيه إلى إصدار آخر بصمت.

## 8. الطرح التدريبي

### البيانات الإلزامية

- الدورة وإصدارها المنشور.
- مركز التدريب إن وجد، والمدرب الأساسي، والمدربون المشاركون.
- لغة التقديم الأساسية.
- نمط التقديم.
- الدولة والمدينة/المنطقة عند الحضور أو الهجين.
- المنطقة الزمنية، البداية والنهاية، والمدة.
- السعة رقم صحيح موجب، وسياسة قائمة الانتظار.
- سعر واضح وعملة ورسوم/ضرائب وسياسة إلغاء.
- حالة التسجيل ومتطلباته السابقة.
- الجمهور المستهدف ومستوى الدورة.

### قيود

1. لا ينشر طرح بلا مدرب أساسي مؤهل، إلا طرح «بانتظار تعيين مدرب» غير قابل للتسجيل.
2. لا تتجاوز التسجيلات المؤكدة السعة؛ الزائد ينتقل لقائمة الانتظار.
3. لا يستخدم السعر العام للدورة بدل سعر الطرح.
4. تغيير الوقت أو المدرب بعد وجود تسجيلات يولد إشعارًا وسجل تغيير وحق إلغاء وفق السياسة.
5. إلغاء الطرح لا يحذف التسجيلات أو المدفوعات، بل يشغل مسار الاسترداد.

## 9. البحث الموحد

### 9.1 أنواع الموارد

`خبراء، مدربون، مستشارون، باحثون/أكاديميون، مراكز تدريب، دورات/طروحات`

### 9.2 مرشحات مشتركة

- الاسم: مستقل عن التخصص.
- المجال/التخصص/الممارسة من التصنيف.
- الدولة من القائمة المرجعية.
- اللغة من اللغات السبع.
- نمط التنفيذ أو التقديم.
- التوفر الزمني.
- التقييم ودرجة الثقة، مع إظهار حجم العينة.

### 9.3 مرشحات الدورات

- المجال التدريبي.
- التخصصات.
- مستوى الدورة.
- اللغة.
- الدولة/المدينة أو عن بعد.
- نمط التقديم.
- التاريخ.
- السعر والنطاق المالي.
- المركز والمدرب والاعتماد.
- وجود مقاعد متاحة.

## 10. جدول نتائج البحث عن دورة

النتيجة الأساسية **جدول واحد**، يمثل كل صف طرحًا يمكن للعميل اختياره، مع تجميع الطروحات التابعة للدورة عند الطلب.

| ترتيب العمود | العمود | المصدر | قابل للفرز | قابل للتصفية |
|---:|---|---|:---:|:---:|
| 1 | رقم تسلسل | العرض | لا | لا |
| 2 | اسم الدورة وتطابق/تشابه الاسم | Course + SearchExplanation | نعم | نعم |
| 3 | المجال التدريبي | Classification | نعم | نعم |
| 4 | التخصص | Classification | نعم | نعم |
| 5 | المستوى | CourseVersion | نعم | نعم |
| 6 | مالك المحتوى | Rights/Party | نعم | نعم |
| 7 | المركز | TrainingCenter | نعم | نعم |
| 8 | المدرب/المدربون | TrainerAssignment | نعم | نعم |
| 9 | اللغة | CourseOffering | نعم | نعم |
| 10 | الدولة/النمط | CourseOffering | نعم | نعم |
| 11 | التاريخ والمدة | CourseOffering | نعم | نعم |
| 12 | المقاعد | CapacityProjection | نعم | نعم |
| 13 | التقييم والثقة/العينة | ReputationSnapshot | نعم | نعم |
| 14 | السعر والعملة | CourseOffering | نعم | نعم |
| 15 | إجراءات | Compare/Details/Enroll | لا | لا |

### قواعد الجدول

1. رؤوس الأعمدة ومحاذاتها ثابتة عند التمرير وتضيق الشاشة.
2. لا يدمج السعر أو المدرب أو الموعد من طروحات مختلفة في صف واحد مضلل.
3. توضح درجة التشابه سبب المطابقة، ولا تعرض كجودة للدورة.
4. الصفوف القابلة للمقارنة تستخدم إصدار العملة/السعر نفسه أو تعرض التحويل كتقدير منفصل.
5. يسمح بفرز متعدد مع بيان ترتيب المفاتيح.

## 11. نتائج بحث المهنيين والمراكز

| النوع | أعمدة الهوية | أعمدة التخصص | أعمدة القرار |
|---|---|---|---|
| خبير/مستشار/باحث | الاسم، الدولة، العضوية | المجال، التخصص، الممارسة | التوفر، السعر، السمعة، الثقة، مقارنة/ملف/طلب |
| مدرب | الاسم، الدولة، اللغات | المجال التدريبي، التخصص، مستويات الدورات | الدورات، التوفر، السمعة، مقارنة/ملف |
| مركز | الاسم، الدولة، نوع الكيان | المجالات والتخصصات | الدورات والطروحات والمدربون والتقييم، ملف المركز |

الاسم حقل بحث مستقل دائمًا. الضغط على النتيجة يفتح ملفًا عامًا موحدًا يحترم الخصوصية ويعرض التفاصيل التي سمح صاحبها بعرضها.

## 12. المقارنة والقائمة المختصرة

1. يختار المستخدم من 2 إلى حد أقصى تضبطه الواجهة دون فقد المرشحين.
2. تعرض المقارنة الحقول نفسها في صفوف متوازية.
3. تبرز الاختلافات ولا تخفي القيم غير المتوفرة؛ «غير معروف» ليست صفرًا.
4. تحفظ معايير البحث وإصدار التصنيف ووقت الأسعار.
5. يستطيع الزائر البدء، ثم تنقل قائمته إلى حسابه بعد الدخول بموافقته.
6. إضافة للقائمة المختصرة لا تعني قبولًا أو تعاقدًا أو تسجيلًا.

## 13. الملفات العامة المرتبطة بالبحث

### صفحة المركز

- الهوية القانونية والموقع والتواصل المسموح.
- المجالات والتخصصات.
- الدورات وإصداراتها المنشورة والطروحات المفتوحة.
- المدربون المرتبطون.
- المرافق والأنماط والسعة المعلنة.
- الاعتمادات والأدلة العامة.
- التقييم ودرجة الثقة وحجم العينة.

### صفحة المدرب/الخبير/المستشار/الباحث

- الهوية المهنية المختصرة واللغات والدولة.
- التصنيفات والبصمات المنشورة.
- الأدلة المتحقق منها المسموح عرضها.
- الخدمات أو الدورات أو المنشورات بحسب الدور.
- التوفر والأسعار المسموحة.
- التقييم والسياق والعينة.

## 21. معايير إغلاق الحزمة

1. كل اختيار بحث أو دورة يعود إلى معرف مفهوم وإصدار صالح.
2. الاسم والتخصص منفصلان في البحث.
3. نتائج الدورات صف لكل طرح وتدعم الفرز والمقارنة.
4. يفتح كل مورد ملفه العام الموحد وفق الخصوصية.
5. لا تنشأ دورة قبل التصنيف وفحص التشابه والحقوق.
6. لا تخلط الدورة بالحقيبة أو الإصدار أو الطرح.
7. المركز والمدرب والمالك علاقات مستقلة قابلة للتدقيق.
8. توجد حالات نجاح وفشل وحدود وأمن وأداء لكل متطلب حرج.

**القرار:** الحزمة الثالثة مكتملة تصميميًا للمتطلبات SRC وTRN. تبقى L وA معلقتين على تحميل التصنيف والكتالوج الكامل، محرك الفهرسة، خدمة منع الازدواج، تخزين الحقوق، واختبارات الأداء وUAT الحية.
