# قاموس البيانات المركزي — EIM 6 / V70

**الحالة:** قاموس منطقي موحد؛ المرجع السابق لتفصيل الحقول يبقى صالحًا إلى أن
تكتمل مصفوفة المطابقة مع DDL.

## 1. الأنواع القياسية

| المفهوم | النوع/المعيار |
|---|---|
| المعرف الداخلي | `uuid` مولد من المنصة |
| رمز الأعمال | `varchar` مضبوط وفريد ضمن نطاقه |
| البريد | `citext` بعد التطبيع والتحقق |
| الهاتف | E.164، في حقل مستقل |
| الدولة | ISO 3166-1 alpha-2 |
| العملة | ISO 4217 |
| اللغة | BCP 47 |
| اللحظة الزمنية | `timestamptz` |
| التاريخ المدني | `date` |
| المدة بالأيام | `integer` موجب أو صفر وفق القاعدة |
| المبلغ الجديد | `amount_minor bigint` + `currency_code` |
| الدرجة | `numeric` مع حد أدنى وأقصى صريحين |
| البيانات الممتدة | `jsonb` مع `schema_version` |
| بصمة الملف | SHA-256 |

## 2. الحقول المشتركة

| الحقل | المعنى | القاعدة |
|---|---|---|
| `id` | المعرف الداخلي | ثابت وغير قابل لإعادة الاستخدام |
| `public_id` | معرف العرض/التكامل | لا يكشف التسلسل |
| `status_code` | الحالة الحالية | من قائمة مضبوطة |
| `created_at/by` | الإنشاء | إلزامي |
| `updated_at/by` | آخر تعديل | يحدّث ذريًا |
| `version_no` | قفل تفاؤلي/نسخة | يزيد فقط |
| `effective_from/to` | مدة النفاذ | النهاية بعد البداية |
| `archived_at/by` | الأرشفة | لا تعني الحذف |
| `source_code` | مصدر البيان | يدوي/استيراد/اشتقاق/تكامل |
| `classification_code` | تصنيف السرية | مستقل عن صلاحية الدور |

## 14. درجات الإلزام

- `R`: إلزامي دائمًا.
- `C`: إلزامي بشرط موثق.
- `O`: اختياري.
- `S`: حساس ويخضع لسياسة عرض.
- `D`: مشتق ولا يدخل يدويًا.
- `H`: تاريخي لا يعدل بعد الإقفال.

## 15. قواعد جودة البيانات

- لا يوجد عمودان يحملان المعنى نفسه في مخططين مختلفين.
- الدول من ISO 3166-1 alpha-2 وليست نصًا حرًا.
- العملات من ISO 4217، واللغات من BCP 47.
- السنوات والمدد أعداد صحيحة ضمن حدود منطقية.
- كل حالة من قائمة انتقال مضبوطة.
- كل `jsonb` موسع يحمل `schema_version`.
- كل حقل مشتق يحمل المصدر والإصدار ووقت الحساب.
- الملفات المتعددة تحفظ كسجلات مستقلة ولا تكدس في عمود واحد.
