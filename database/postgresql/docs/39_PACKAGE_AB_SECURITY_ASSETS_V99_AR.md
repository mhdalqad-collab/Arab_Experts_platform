# الحزمة AB — الأصول التقنية والثغرات والمعالجة الأمنية V99

تنشئ الحزمة سجلًا موحدًا للأصول التقنية وبيئاتها ودرجة حرجيتها وتصنيف البيانات ومالكها وأمينها والمورد المرتبط بها. كما توثق الاعتماديات بين الأصول لتوضيح المسارات الحرجة وأثر الخلل المتسلسل.

تسجل الثغرة ومصدر اكتشافها وشدتها وموعد معالجتها، وتلزم ربط الثغرات الحرجة والعالية بسجل المخاطر المؤسسي. وتفصل خطة المعالجة عن عملية التحقق اللاحقة، مع أدلة تنفيذ ومراجع مستقل عن المنفذ.

لا تعتبر الثغرة مغلقة لمجرد تطبيق تعديل؛ يلزم تحقق ناجح لاحق ودليل ومراجعة مستقلة. ولا تنفذ هذه الحزمة فحصًا هجوميًا أو إصلاحًا آليًا، بل تحكم السجل والقرار والأدلة ودورة المعالجة.

## مخرجات الحزمة

- سجل الأصول التقنية والتصنيف والملكية.
- خريطة الاعتماديات والمسارات الحرجة.
- سجل الثغرات والأولوية ومواعيد المعالجة.
- خطط إصلاح وضوابط تعويضية موثقة.
- جولات تحقق مستقلة وأدلة نتائج.
- منظور يكشف التأخر وغياب الخطة أو التحقق.
- تراجع آمن يرفض إزالة أدلة المعالجة الأمنية.
