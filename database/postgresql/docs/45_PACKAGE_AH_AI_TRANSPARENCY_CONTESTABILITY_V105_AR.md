# الحزمة AH — شفافية القرارات الخوارزمية وحق الاعتراض V105

تكمل هذه الحزمة حوكمة الذكاء الاصطناعي بعد صدور النتيجة. فهي لا تنشئ قرارًا آليًا موازيًا، بل تربط سجل القرار الموجود بالنموذج الذي أصدره، وتضيف تفسيرًا مفهومًا، وإشعارًا قابلًا للإثبات، ومراجعة بشرية، وحقًا منظمًا في الاعتراض، وسجلًا للحوادث الخوارزمية.

## القواعد الحاكمة

- لا تكفي درجة المطابقة وحدها؛ يجب بيان العوامل الحاسمة والقيود ودرجة اليقين.
- يحتفظ العميل بحق القرار النهائي، ولا يتحول ترتيب المرشحين إلى قرار ملزم.
- إذا كانت المراجعة البشرية مطلوبة فلا تعد المعالجة مكتملة قبل توثيقها.
- يصل الإشعار بلغة محددة ويبين طريقة الاعتراض، ولا يعد مجرد إنشاء الإشعار تسليمًا له.
- لا يراجع الاعتراض صاحبه، وتوثق النتيجة وأسبابها وأدلتها.
- قلب النتيجة أو تعديلها يحتاج سجل تجاوز بشري وأدلة.
- لا يغلق الحادث قبل توثيق السبب الجذري والإجراء التصحيحي والتحقق المستقل.
- لا يختزل التفسير في كشف الأسرار التقنية أو البيانات الشخصية؛ بل يقدم سببًا مفهومًا وكافيًا للمراجعة.

## بوابة الإجراءات الواجبة

يعرض المنظور `governance.v_ai_decision_due_process` النقص الأهم لكل قرار: المراجعة البشرية، أو التفسير، أو الإشعار وحق الاعتراض، أو تأخر الفصل في الاعتراض، ثم يعلن اكتمال الإجراءات فقط بعد استيفائها.

## التراجع

التراجع غير هادم: يرفض إذا وجدت إشعارات مسلمة أو اعتراضات أو تجاوزات بشرية أو حوادث، لأن هذه السجلات أدلة حوكمة لا يجوز إسقاطها آليًا.
