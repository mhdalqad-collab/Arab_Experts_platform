# حزمة الحفظ النهائية EIM 6 — V112

هذه نسخة مجمدة للحفظ والاعتماد، مبنية على آخر نطاق منطقي V110، مع تحسينات الجودة والأمن ووثيقة القبول في V112. لم تُحذف منها بيانات أو وظائف سابقة.

## أهم الملفات

- `README.md`: مدخل المشروع وطريقة التشغيل.
- `database/postgresql/docs/51_FINAL_ACCEPTANCE_REVIEW_V112_AR.md`: تقرير القبول والنواقص.
- `database/postgresql/migrations/`: مخطط PostgreSQL الأمامي.
- `database/postgresql/seeds/`: البيانات المرجعية.
- `public/eim/`: النموذج المرئي ووحداته.
- `app/` و`db/` و`worker/`: المصدر التنفيذي وطبقة الخدمات.
- `tests/`: الاختبارات الآلية.
- `release/FILE_SHA256SUMS.txt`: بصمات ملفات الحزمة، ويولد وقت التصدير.

## التشغيل المحلي للمطور

يتطلب Node.js 22.13 أو أحدث:

```bash
npm ci
npm test
npm run dev
```

## ملاحظة اعتماد

هذه الحزمة مرجع تصميم وتنفيذ معتمد، وليست تصريحًا باستقبال بيانات أو مدفوعات حقيقية قبل إغلاق بوابات التشغيل الواردة في تقرير القبول النهائي.
