# الحزمة L — مؤشرات Canary والتوصيات وحدود السلامة — V83

## النتيجة

تحسب الحزمة مؤشرات نافذة Canary من السجلات الفعلية وتنتج توصية تشغيلية.
التوصية غير ملزمة ولا ترفع نسبة التفعيل آليًا. الإجراء الآلي الوحيد المسموح
هو الإيقاف الوقائي عند تجاوز حد سلامة.

## المؤشرات

- عدد الأوامر داخل عينة الإنفاذ.
- عدد ومعدل الأوامر الممنوعة.
- عدد ومعدل الأوامر الفاشلة.
- زمن الاستجابة عند النسبة المئوية 95.
- أحداث Outbox التي وصلت إلى Dead Letter.
- مدة النافذة وحجم العينة.

## التوصيات

- `CONTINUE_MONITORING`: المدة أو العينة غير كافية.
- `PROMOTE_REVIEW`: المؤشرات سليمة؛ يمكن بدء مراجعة بشرية للترقية.
- `PAUSE_REQUIRED`: تجاوز تشغيلي يستلزم الإيقاف والتحليل.
- `ROLLBACK_REVIEW`: فشل أو Dead Letter يستلزم مراجعة الرجوع.

## قواعد الأتمتة

- لا توجد ترقية آلية إطلاقًا.
- عند تجاوز حد المنع أو الخطأ أو زمن P95 أو ظهور Dead Letter:
  - تغلق النافذة بالفشل.
  - تصبح نسبة التطبيق صفرًا.
  - تفعل حالة الإيقاف الطارئ.
  - يسجل الحدث والفاعل والمقاييس والأسباب.
- استئناف الخطة أو الرجوع أو الترقية يظل عبر إجراء الحزمة J بصلاحياته.

## الأثر التدقيقي

يحفظ جدول التوصيات لقطة المقاييس والحدود والأسباب والفاعل ومعرف الارتباط،
ويوفر منظورًا لأحدث توصية لكل خطة.
