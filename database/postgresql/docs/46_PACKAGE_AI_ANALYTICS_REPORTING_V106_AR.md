# الحزمة AI — حوكمة المؤشرات والتحليلات والتقارير V106

تنشئ هذه الحزمة مصدرًا مؤسسيًا واحدًا لتعريف مؤشرات شبكة الخبراء العرب، وتفصل بين تعريف المؤشر ونسخته والقيمة المقاسة والتقرير الذي يعرضها. وبذلك لا يصبح الرقم الظاهر في الصفحة الرئيسية أو لوحة الإدارة حقيقة لمجرد عرضه، بل يرتبط بتعريف معتمد ومصدر بيانات وفترة قياس ودرجة حداثة وأثر تدقيق.

## المبادئ

- لكل مؤشر رمز وتعريف ومالك وأمين بيانات ومصدر بيانات معتمد.
- تحفظ معادلة المؤشر وقواعد الإدراج والاستبعاد والحبيبات الزمنية في نسخة مؤرخة.
- الأبعاد التحليلية مستقلة، ويطبق عليها حد أدنى لحجم المجموعة لحماية الخصوصية.
- كل قيمة تحفظ فترة القياس وحجم العينة ومرجع الحساب وبصمته وموعد انتهاء حداثتها.
- البيانات التجريبية أو الاصطناعية لا تعرض كبيانات تشغيلية حقيقية، ويلزم التصريح عنها.
- تعريف التقرير منفصل عن كل تشغيل فعلي له، والتشغيل المنشور يحتفظ بالقيم المستخدمة وبصمة الناتج.
- لا يسمح التقرير العام بعرض مؤشر مصنف داخليًا أو سريًا.
- لا تستخدم الواجهة إحصاءات مقنعة شكليًا لكنها غير قابلة للتتبع.

## بوابة الجاهزية

يعرض المنظور `analytics.v_report_publication_readiness` ما إذا كان التقرير صالحًا للعرض، أو أن تعريفه غير نشط، أو أن تشغيله غير منشور، أو أن بياناته قديمة، أو أنه يخالف تصنيف الحساسية، أو يحتوي بيانات اصطناعية تحتاج إلى إفصاح.

## التراجع

يرفض التراجع عند وجود قيم مقاسة أو تعريفات معتمدة أو تقارير منشورة، حمايةً للأثر المؤسسي والتاريخي.
