# الحزمة AJ — حوكمة الإشعارات والمراسلات وقابلية التسليم V107

توحّد هذه الحزمة الإشعارات التي تصل إلى الخبراء والمدربين والمراكز والعملاء والمشغلين. وهي تفصل موضوع الإشعار وتفضيلات المستخدم والقالب والرسالة ومحاولة التسليم، بحيث يمكن إثبات ما أرسل، ولمن، ولماذا، وبأي قناة، وما إذا وصل فعلًا.

## القواعد

- تصنف الموضوعات إلى إلزامية ومعاملاتية واختيارية.
- لا يجوز تعطيل إشعار أمني أو مالي مهم باعتباره إعلانًا اختياريًا.
- تتطلب الموضوعات الاختيارية تفضيلًا فعالًا وموافقة عند الحاجة.
- تحترم القناة واللغة والمنطقة الزمنية وساعات الهدوء ونمط الملخص.
- لا تحفظ بيانات الاتصال الحساسة داخل سجل الإرسال؛ يستخدم مرجع مشفر وبصمة.
- تمنع قيمة idempotency تكرار الرسالة نفسها.
- كل محاولة تسليم مستقلة، مع نتيجة وإعادة محاولة مقيدة بالأخطاء المؤقتة.
- حالات الارتداد والشكاوى والقيود القانونية تحفظ في سجل منع مركزي.
- لا تعني حالة «أُرسلت» أنها «وصلت»؛ التسليم له دليل مستقل.

## بوابة الجاهزية

يفحص المنظور `communication.v_message_delivery_readiness` صلاحية القالب والقناة، وانتهاء الرسالة، وسجل المنع، وموافقة الموضوع الاختياري، ثم يميز بين الجاهزية للإرسال والتسليم المثبت.

## التراجع

يرفض التراجع عند وجود تفضيلات أو منع أو رسائل مرسلة أو أدلة تسليم، منعًا لفقدان حقوق المستخدم والأثر التدقيقي.
