# الحزمة S — الاعتمادية وSLA/SLO وميزانية الخطأ V90

تثبت الحزمة تعريفًا قابلًا للإصدار لكل مؤشر تشغيلي: التوافر، ومعدل النجاح، وزمن P95، وMTTA، وMTTR، وتأخر Outbox. لكل هدف نطاق ووحدة ونافذة قياس وحد تحذير وحد حرج لسرعة استهلاك ميزانية الخطأ.

تحتفظ القياسات بلقطة مصدر قابلة للتدقيق ولا تعيد كتابة التاريخ. تعرض لوحة موحدة آخر نتيجة لكل هدف، بينما تحسب لوحة الحوادث MTTA وMTTR للحوادث الفعلية. تجاوز الميزانية يولد حدثًا للمراجعة ولا يغير الإنتاج تلقائيًا؛ قرار تجميد التغييرات أو خفض التفعيل يبقى محكومًا.
