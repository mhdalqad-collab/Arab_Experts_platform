# الحزمة C — توحيد الخبرات المهنية ومحتوى الدورات V74

## 1. نطاق الحزمة

توحد الحزمة خمس عائلات خبرة مهنية في سجل واحد، وتحوّل `training.courses`
منطقيًا إلى هوية محتوى مستقلة عن الطرح. تبقى الجداول القديمة ومسارات القراءة
الحالية دون حذف أو إيقاف.

## 2. توحيد الخبرات

تشمل عملية النسخ:

- الخبرة الوظيفية.
- خبرة المشاريع.
- خبرة التدريب.
- خبرة الاستشارات.
- خبرة البحث.

يفصل السجل بين `record_type_code` الذي يحدد مصدر الممارسة (وظيفة، مشروع،
تدريب، استشارة، بحث)، و`experience_type_code` الذي يحدد طبيعة الخبرة المهنية
مثل التقنية أو القيادية. ويحفظ الحقول المشتركة، كما يحفظ `source_snapshot` الكامل للسجل
الأصلي، واسم جدول المصدر ومعرفه. لذلك لا تضيع بيانات متخصصة مثل عدد المشاركين
أو نمط التنفيذ أو العميل أو التقييم.

## 3. محتوى الدورة

الفصل المعتمد:

- `course_contents`: هوية المحتوى الثابتة.
- `course_content_versions`: النسخ المعتمدة.
- `course_content_version_names`: الأسماء متعددة اللغات.
- `course_offerings`: الطرح التشغيلي القائم دون تغيير.
- `course_offering_content_links`: رابط الطرح بالنسخة الموحدة.

يحافظ النسخ الخلفي على UUID القديم نفسه للمحتوى والنسخة، مما يمنع كسر
العلاقات والتكاملات.

## 4. منع الازدواجية

تولد بصمتان:

1. العنوان المطبّع مع توقيع التصنيف.
2. بصمة المحتوى، إذا كانت متاحة.

التطابق يولد مرشح مراجعة فقط. الخيارات البشرية هي استخدام الموجود، أو إنشاء
نسخة جديدة، أو إبقاء المحتويين منفصلين، أو اعتماد الدمج. لا يحدث دمج آلي.

## 5. استقلال الطرح والحقوق

- الدورة لا تساوي الطرح.
- تعدد المدربين أو المراكز لا يكرر المحتوى.
- اختلاف الموعد أو السعر أو الدولة أو نمط التقديم ينشئ طرحًا، لا دورة جديدة.
- الملكية والتأليف وحقوق التقديم لا تنتقل بسبب النسخ الخلفي.
- حقوق المحتوى ستنقل إلى مخطط `rights` في حزمة لاحقة مع توافق كامل.

## 6. المصالحة

تسجل الحزمة عدد المصدر والهدف والمطابق والاستثناء لكل من:

- الخبرات.
- الدورات.
- نسخ المحتوى.
- الطروحات.

وتبقى تقارير المصالحة قابلة لإعادة التنفيذ قبل التحويل.

## 7. التراجع

يرفض ملف التراجع العمل إذا:

- وجد محتوى أصلي أنشئ في النموذج الجديد.
- اتخذ قرار بشري بشأن التكرار.
- عدّل سجل خبرة منسوخ بعد إنشائه.

ولا يحذف أعمدة Snapshot أو جداول المصالحة العامة، لأنها قد تستخدمها حزم لاحقة.

## 8. الخطوة التالية

الحزمة D ستنشئ النسخ المتوافقة للعقود والحقوق والجودة في مخططاتها المستهدفة،
مع المعرفات نفسها، والمقارنة، وViews للأسماء القديمة، دون إيقاف الكتابة
الحالية.
