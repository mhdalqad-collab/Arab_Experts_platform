# الحزمة X — الموردون والخدمات الخارجية V95

تثبت الحزمة سجلًا موحدًا للموردين، وتربط كل مورد بالخدمات التي تعتمد عليه ودرجة الحرجية ومخاطر التركّز. كما تحفظ SLA، والمراجعات الأمنية والخصوصية والمالية والأداء، وأدلة التقييم وصلاحيتها.

لا تمنح الجاهزية لمورد غير نشط أو دون مراجعة أمنية وتقييم ساري. وللتبعيات عالية الخطورة يلزم بديل وخطة خروج واختبار قابلية نقل البيانات. لا تُلغى الخدمة آليًا ولا يُستبدل المورد دون قرار محكوم، وتبقى الأدلة التاريخية محفوظة.
