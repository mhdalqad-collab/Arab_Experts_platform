# الحزمة R — معالجة الحوادث والتعلم المؤسسي V89

تغطي الحزمة الرحلة من تعيين مالك الحادث والإقرار به، مرورًا بالتحقيق والاحتواء، إلى الحل والإغلاق الموثق. أضيف تحليل سبب جذري بمراجعة مستقلة، وإجراءات احتوائية وتصحيحية ووقائية، والتحقق من فاعليتها، وسجل للدروس المستفادة يمكن ربطه بأصل معرفي.

لا يسمح PostgreSQL بإغلاق الحادث قبل مراجعة السبب الجذري، ووجود إجراء واحد متحقق على الأقل، وعدم بقاء إجراءات مفتوحة. ويتطلب الحل أو الإغلاق تحققًا أمنيًا إضافيًا. لا تُعد التوصية أو تنفيذ الإجراء دليلًا على الفاعلية ما لم يسجل مراجع مستقل نتيجة التحقق.
