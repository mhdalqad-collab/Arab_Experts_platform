# الحزمة AL — حوكمة الإعدادات والميزات التدريجية والتجارب V109

تجعل هذه الحزمة تطوير المنصة قابلًا للتوسع دون تفعيل كل تغيير لجميع المستخدمين دفعة واحدة. وهي تفصل الإعداد التشغيلي عن علم الميزة وعن التجربة المقاسة.

## القواعد

- لكل إعداد تعريف ونوع وقاعدة تحقق ومالك وتصنيف حساسية.
- كل قيمة إنتاجية إصدار مؤرخ ومعتمد وقابل للتتبع، ولا تحفظ الأسرار نفسها بل مراجعها.
- لكل ميزة مالك ومخاطر وموعد انتهاء وآلية تعطيل طارئ.
- قواعد الإتاحة تحدد البيئة والجمهور والنسبة والفترة والأولوية.
- لا تعمل قاعدة إنتاجية دون موافقة، ولا يبقى علم ميزة بلا تاريخ انتهاء.
- التجربة تبدأ بفرضية ومؤشر رئيسي ومؤشرات حماية وسكان محددين.
- التجربة عالية المخاطر تحتاج موافقة صريحة، ولا تستخدم لتغيير أوزان العميل خفية أو لاتخاذ قرار ملزم عنه.
- التعيين ثابت بالبصمة، ويقبل الانسحاب ويحفظ الموافقة عند وجوبها.
- نتيجة التجربة لا تتحول تلقائيًا إلى تعميم إنتاجي؛ يلزم قرار إصدار مستقل.

## بوابة الجاهزية

يفحص المنظور `governance.v_feature_release_readiness` اعتماد الميزة، وصلاحية علمها، والتعطيل الطارئ، ووجود قاعدة إنتاجية معتمدة، وموافقة التجارب عالية المخاطر.

## التراجع

يرفض التراجع عند وجود إعدادات إنتاجية أو قواعد طرح إنتاجية أو تجارب جارية أو مكتملة، حفاظًا على الأثر التدقيقي.
