# الحزمة W — الحوكمة المالية التشغيلية FinOps V94

تربط الحزمة تكاليف البنية بمراكز تكلفة وخدمات وميزانيات دورية وعملات محددة، وتحفظ كل ملاحظة تكلفة ومصدرها دون استبدال التاريخ. كما تحسب تكلفة الوحدة للأعضاء والبحث والمطابقة والطلبات والعقود والتسجيل في الدورات.

تعرض لوحة الميزانية الاستهلاك والانحراف وحالات ضمن الميزانية أو معرض للخطر أو متجاوز. ولا تسمح بوابة تحسين التكلفة بالمراجعة عندما تكون SLO أو السعة في خطر؛ فخفض التكلفة لا يجوز أن يتجاوز متطلبات الجودة والاعتمادية، ولا تنفذ البوابة أي خفض تلقائي.
