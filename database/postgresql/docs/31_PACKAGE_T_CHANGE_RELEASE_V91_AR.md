# الحزمة T — التغيير والإصدارات والنشر V91

تفصل الحزمة بين طلب التغيير والإصدار وحادثة النشر. كل تغيير يحمل مبررًا وتقييم أثر وخطط تنفيذ وتحقق ورجوع، ويرتبط الإصدار بتغييرات معتمدة وبأثر رقمي ثابت للملفات. يسجل كل نشر حسب البيئة ولا يستبدل تاريخ المحاولات السابقة.

بوابة الإنتاج تمنع النشر عند وجود حادث SEV1/SEV2 مفتوح، أو تجاوز SLO، أو تغيير غير معتمد، أو إصدار فارغ. القرار ناتج قابل للتدقيق وليس تجاوزًا يدويًا صامتًا. ويظل منشئ الإصدار مختلفًا عن معتمده، وتبقى خطة الرجوع إلزامية قبل الموافقة.
