# الحزمة K — منفذ الأوامر المدرك للتفعيل التدريجي — V82

## النتيجة

ترتبط خطة Canary الآن بمسار تنفيذ أوامر قضايا الخدمة. ويبقى السلوك الافتراضي
`MONITOR_ONLY` ما لم توجد خطة معتمدة ونشطة ونسبتها أكبر من صفر.

## طريقة الإصدار والرجوع

- أعيدت تسمية المنفذ السابق إلى
  `delivery.execute_service_case_command_v78`.
- ثبت المنفذ الجديد بالاسم القياسي
  `delivery.execute_service_case_command`.
- يعيد ملف التراجع اسم V78، لذلك لا يحتاج تطبيق API إلى تغيير الاستدعاء.

## حسم نمط التنفيذ

بعد قفل القضية واختيار نسخة سير العمل، يستدعي المنفذ
`delivery.resolve_service_case_enforcement_mode(...)`.

- لا توجد خطة نشطة: `MONITOR_ONLY`.
- مفتاح الإيقاف فعال: `MONITOR_ONLY`.
- القضية خارج عينة Canary: `MONITOR_ONLY`.
- القضية داخل عينة Canary: `ENFORCING`.

## السلوك داخل العينة

- مخالفات الأدوار أو البوابات أو السبب أو التحقق الإضافي تصبح `BLOCK`.
- الانتقال الذي يشترط اعتمادًا يصبح `REQUIRE_APPROVAL`.
- الانتقال السليم ينفذ في المعاملة نفسها ويسجل حدث المرحلة وOutbox.
- إعادة مفتاح الأمر نفسه تعيد النتيجة السابقة ولا تنفذه مرتين.

## الرصد

يعرض المنظور `delivery.v_service_case_enforcement_operations` نمط الإنفاذ
المطبق، وقرار التقييم والتنفيذ، وخطة التفعيل والنسبة ومفتاح الإيقاف.

## قيد السلامة

لا تنشئ هذه الحزمة خطة ولا تعتمدها ولا ترفع نسبتها. يبدأ النظام فعليًا دون
عينة إنفاذ، ولا يتغير إلا عبر إجراءات الحزمة J المحكومة.
