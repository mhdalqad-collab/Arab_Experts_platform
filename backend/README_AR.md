# خدمة EIM Backend — مرحلة التأسيس

خدمة Node.js/TypeScript مستقلة تجعل PostgreSQL 16 مصدر الحقيقة الإنتاجي وفق
ADR-001، وتعمل إلى جانب واجهة Cloudflare أثناء الانتقال التدريجي.

## المتوفر

- Pool PostgreSQL محدود ومهيأ بمهل اتصال وخمول.
- معاملات مع `COMMIT/ROLLBACK` وتحرير الاتصال في جميع الحالات.
- `/health/live` لفحص العملية.
- `/health/ready` لفحص الاتصال ووجود migration `0890_v113_backend_slo_scheduling_notifications`.
- `/v1/meta` لتعريف الخدمة ومصدر الحقيقة.
- correlation ID واستجابات JSON ورؤوس أمن موحدة.
- graceful shutdown مع حد زمني.
- OIDC/JWKS مع تحقق issuer وaudience والخوارزميات المسموحة.
- ربط subject الخارجي بحساب EIM دون الاعتماد على البريد وحده.
- استخراج الأدوار والصلاحيات ونطاقات المنظمات من PostgreSQL.
- Authorization مركزي للصلاحية والنطاق وstep-up authentication.
- اختبارات إعدادات وHTTP مستقلة عن قاعدة حية.
- وصول مقيد لوثائق مراجعة نشر الملف المهني بصلاحية مستقلة ومصادقة معززة.
- جلسات تنزيل أحادية الاستخدام لا تتجاوز ثلاث دقائق، مرتبطة بالمراجع المعيّن والدليل الموجود في اللقطة المجمدة، مع سبب إلزامي وسجل تدقيق حرج.
- ملاحظات مراجعة منظمة مرتبطة بالملف أو البصمة أو الدليل، مع استجابة العضو وقرار الإغلاق أو إعادة الفتح، ومنع التوصية قبل إغلاق الملاحظات الجوهرية.
- حزم تعديل مراجعة مرقمة تحفظ اللقطة الأصلية، وتعرض مقارنة قبل/مقترح، وتتطلب قرار المراجع قبل إغلاق الملاحظة أو إصدار التوصية.
- لقطة نشر موحدة تجمع الأصل والتعديلات المقبولة، ببصمتي سلامة للمحتوى وحالة المصادر، وتصبح شرطًا إلزاميًا قبل التوصية.
- ختم قرار الاعتماد ببصمة SHA-256 وإنشاء نسخة نشر ثابتة، مع قصر البحث العام على النسخ المختومة السليمة والنشطة.
- إدارة محكومة لتعليق النسخة المنشورة واستعادتها أو سحبها، مع سبب إلزامي وصلاحية مستقلة وسجل تاريخي غير قابل للحذف.
- مراقبة صلاحية الأدلة المختومة بسياسة 30 يومًا للتنبيه و14 يومًا للمهلة، مع سجل تقييم وتنبيهات وتعليق آلي محكوم عند تجاوز المهلة.
- تحكم موثوق بالمهمة اليومية لإعادة التحقق، مع قفل يمنع التوازي، ثلاث محاولات، كشف التشغيل المتعطل، سجل نتائج وتدقيق كامل.
- تسليم تنبيهات إعادة التحقق داخل التطبيق وربطها بصندوق الإرسال العام، مع منع التكرار، احترام قنوات العضو، التصعيد والإقرار بالاستلام.
- موزع رسائل خارجي محمي بعقود إيجار قصيرة ودفعات مقيدة، مع إعادة محاولة متدرجة، تسجيل نتائج المزود، ومنع القنوات المرتدة نهائيًا.
- لوحة تشغيل لتسليم الإشعارات وصندوق رسائل فاشلة، مع استعادة أو إلغاء محكومين ومنع الاستعادة قبل معالجة القنوات المحظورة.
- أهداف واعتمادية قابلة للضبط لتسليم الرسائل، مع قياسات زمنية وكشف خرق وفتح حادث تشغيلي غير مكرر وإغلاق موثق.
- تشغيل يومي غير مكرر لقياس SLO وإشعارات فورية داخل التطبيق لمسؤولي المنصة عند فتح حوادث التسليم.

## التشغيل المحلي

```bash
npm run backend:build
DATABASE_URL='postgresql://...' npm run backend:start
```

## الاختبار

```bash
npm run backend:test
```

## بوابة الجاهزية

لا تصبح الخدمة Ready لمجرد نجاح الاتصال؛ يجب أن يحتوي
`integration.schema_migrations` على `0890_v113_backend_slo_scheduling_notifications`.

## حدود المرحلة

لا تزال endpoints الخاصة بالمجالات في واجهة D1 الحالية. تحول في المراحل
التالية إلى هذه الخدمة بعد إضافة OIDC وAuthorization وعقود المجال واختبارات
المصالحة.
