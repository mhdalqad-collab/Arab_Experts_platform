# قاموس قواعد الأعمال المؤسسي V6

| الرمز | القاعدة | موضع الإنفاذ |
|---|---|---|
| BR-ID-01 | حساب دخول واحد لكل شخص مع تعدد العضويات | IAM + Membership |
| BR-ID-02 | المنظمة أو الشخص يسجل مرة واحدة في `core.parties` | Unique/dedup service |
| BR-PR-01 | الملف العام يعرض فقط الحقول المسموحة والغرض الساري | Privacy projection |
| BR-RB-01 | الصلاحية = دور + نطاق + مدة + حالة فعالة | RBAC query |
| BR-RB-02 | مقدم طلب الاعتماد لا يعتمد طلبه | Trigger |
| BR-RB-03 | التفويض لشخص آخر ولمدة محددة ولهدف واحد | CHECK + approval |
| BR-RB-04 | طلب الاسترداد واعتماده منفصلان | SOD |
| BR-KN-01 | المنشور والأصل المعرفي لا ينشران دون إصدار معتمد | Workflow |
| BR-KN-02 | كل تغيير محتوى ينشئ إصدارًا ولا يكتب فوق الإصدار المنشور | Unique/version trigger |
| BR-EV-01 | الفعالية المنشورة لها وقت بداية ونهاية ومكان أو رابط صالح | Application + CHECK |
| BR-PR-02 | الموافقة مرتبطة بنسخة إشعار وغرض ويمكن سحبها دون محو التاريخ | Consent history |
| BR-AU-01 | حدث التدقيق لا يعدل ولا يحذف | Append-only triggers |
| BR-IN-01 | الأسرار تحفظ كمراجع إلى Secret Manager لا كنص | CHECK + deployment |
| BR-IN-02 | الرسالة الواردة تعالج مرة واحدة بالمفتاح الخارجي | Unique idempotency |
| BR-TR-01 | الدورة القياسية لا تكرر؛ التغيير الجوهري إصدار جديد | Training model |
| BR-SR-01 | انتقال حالة طلب الخدمة يتم عبر قواعد انتقال وسجل تاريخ | Workflow/history |

## أولوية الإنفاذ

قواعد سلامة البيانات في قاعدة البيانات، وقواعد السياق في خدمة المجال، وقواعد
العرض في واجهة الاستخدام. لا تعتبر إخفاءات الواجهة حماية أمنية.
