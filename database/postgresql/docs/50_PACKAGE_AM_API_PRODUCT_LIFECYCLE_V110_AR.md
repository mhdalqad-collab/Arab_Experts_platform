# الحزمة AM — حوكمة منتجات API ودورة الإصدار والاستهلاك V110

تضيف هذه الحزمة طبقة المنتج فوق نقاط API والعملاء الموجودين. فيصبح لكل واجهة غرض ومالك وجمهور وشروط وإصدارات واشتراكات وحصص وخطة إهمال، بدل منح اتصال تقني مفتوح بلا دورة حياة.

## القواعد

- المنتج العام لا يعرض بيانات غير مصنفة للعامة.
- لكل إصدار عقد OpenAPI ببصمة وروابط لعقود البيانات.
- الإصدار الكاسر يحتاج دليل انتقال، ولا يصدر إنتاجيًا دون موافقة.
- الاشتراك محدد بالمستهلك والإصدار والبيئة والغرض والفترة وأقل الصلاحيات اللازمة.
- الحصة تحدد المعدل اليومي والدقيقة والاندفاع والتزامن وحجم الحمولة.
- القياس يفصل النجاح وأخطاء المستهلك وأخطاء الخادم والخنق والزمن المنظوري.
- الإهمال لا يعني الإيقاف الفوري؛ يلزم إشعار ومهلة وبديل ودليل انتقال.
- انتهاء الاشتراك أو الإصدار يوقف الجاهزية، ولا يحذف سجل الاستخدام.

## بوابة الجاهزية

يفحص المنظور `integration.v_api_subscription_readiness` حالة المنتج والإصدار والاشتراك وصلاحيته وسياسة الحصة وإشعار الإهمال قبل السماح بالوصول.

## التراجع

يرفض التراجع عند وجود استخدام أو اشتراكات تشغيلية أو إشعارات إهمال، حفاظًا على حقوق المستهلكين وأثر التكامل.
