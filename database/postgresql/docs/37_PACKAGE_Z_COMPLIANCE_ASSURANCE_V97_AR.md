# الحزمة Z — الامتثال والضوابط وأدلة التأكيد V97

تؤسس الحزمة سجلًا مؤسسيًا للأطر النظامية والمعايير والالتزامات القابلة للتطبيق، ثم تربط كل التزام بضابط واحد أو أكثر مع بيان درجة التغطية ومسوغ الربط. ويفصل النموذج بين مالك الضابط ومنفذه ومختبره ومراجعه لتقليل تعارض المصالح.

يحفظ كل اختبار نطاق الفترة والعينة والنتيجة والاستثناءات والأدلة وخطة المعالجة. ولا تقبل نتيجة جزئية أو غير فعالة من دون إجراء تصحيحي وموعد استحقاق. ويعرض منظور التأكيد سبب عدم الجاهزية: غياب الربط، غياب الاختبار، ضعف الفاعلية، أو غياب المراجعة المستقلة.

لا تمنح المنصة شهادة امتثال تلقائية؛ فهي تعرض حالة الأدلة والضوابط لتدعم قرار الجهة المخولة. ولا يُغلق عدم الامتثال من دون اختبار لاحق ومراجعة مستقلة موثقة.

## مخرجات الحزمة

- سجل أطر ومعايير بإصداراتها وولاياتها القضائية.
- سجل التزامات وقواعد انطباق وتوقعات أدلة.
- مكتبة ضوابط موحدة بمالك ومنفذ ودورية.
- خريطة متعددة العلاقات بين الالتزامات والضوابط.
- اختبارات فعالية وأدلة وخطط معالجة.
- منظور لحالة التأكيد وأسباب الفجوة.
- تراجع يرفض محو أدلة التأكيد الموجودة.
