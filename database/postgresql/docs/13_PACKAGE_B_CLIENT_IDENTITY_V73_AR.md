# الحزمة B — توحيد هوية العميل والعلاقات المؤسسية V73

## 1. القرار

البنية الحالية صحيحة في أصلها: `crm.client_accounts.client_party_id` يشير إلى
`core.parties`. لذلك لا تنشئ الحزمة سجل عميل بديلًا، بل تضيف طبقة حل هوية
وحماية من التكرار.

## 2. ما أضيف

- مفاتيح مطابقة Party مخزنة كبصمات SHA-256.
- مرشحو التكرار مع الدرجة والتفسير.
- مراجعات بشرية متعددة المراحل.
- قرارات اختيار القيم على مستوى الحقول.
- خطة دمج قابلة للمراجعة قبل التنفيذ.
- سجل أحداث كامل لأي تنفيذ مستقبلي.
- رابط العميل بالـParty القانوني المعتمد.
- أدوار جهات الاتصال المؤسسية مع التفويض والفترة.
- سجل تشغيل لعمليات المطابقة والنسخ الخلفي.
- عرض قائمة مراجعة التكرار وعرض الهوية القانونية للعميل.

## 3. قواعد منع الدمج الخاطئ

1. التطابق لا يعني الدمج.
2. رقم التسجيل القانوني أقوى من الاسم.
3. البريد أو الهاتف لا يستخدم إلا إذا كان موثقًا.
4. تشابه الاسم والدولة يرسل للمراجعة فقط.
5. لا توجد دالة تنفيذ دمج في هذه الحزمة.
6. يلزم تحديد Party قانوني معتمد وقرار حقلي قبل التنفيذ مستقبلًا.
7. كل قرار يربط بالمراجع والزمن والتفسير.

## 4. النسخ الخلفي

النسخ الخلفي قابل لإعادة التشغيل ويستخدم `ON CONFLICT DO NOTHING`:

- ينشئ رابط هوية لكل حساب عميل مع إبقاء المصدر والمعتمد متساويين.
- ينسخ جهات الاتصال إلى سجل الأدوار ويحفظ `legacy_client_contact_id`.
- يولد مفاتيح التسجيل ووسائل الاتصال الموثقة والاسم/الدولة.
- يولد قائمة مرشحين؛ لا يغير حالة Party.

## 5. الخصوصية

- لا تحفظ قيمة البريد أو الهاتف في مفاتيح المطابقة.
- تحفظ البصمة المشفرة وتلميحًا قصيرًا فقط.
- قائمة المراجعة إدارية ولا تعرض للعامة.
- الوصول إلى بيانات المقارنة يتطلب صلاحية إدارة الهوية.

## 6. ما لم يتغير

- لا حذف أو أرشفة أو دمج لأي Party.
- لا تعديل لمفاتيح `crm.client_accounts`.
- لا حذف لـ`crm.client_organizations` أو`crm.client_contacts`.
- لا تحويل لواجهات التطبيق إلى الجداول الجديدة بعد.

## 7. التحقق المطلوب

- عدد روابط الهوية يساوي عدد حسابات العملاء.
- عدد أدوار الاتصال المنسوخة يساوي عدد جهات الاتصال القديمة.
- لا توجد مفاتيح مطابقة بقيم أصلية حساسة.
- كل مرشح يحوي Party مختلفين وبترتيب ثابت.
- إعادة تنفيذ migration لا تنشئ سجلات مكررة.
- لا يمكن إنشاء خطة دمج لطرف مع نفسه.
- ملف التراجع يرفض العمل بعد وجود قرار بشري.

## 8. الخطوة التالية

الحزمة C ستوحد الخبرات المهنية ومحتوى الدورات وإصداراتها عبر نسخ خلفي
متدرج وواجهات توافق، دون تغيير الطروحات أو الملكية أو حقوق التسليم.
