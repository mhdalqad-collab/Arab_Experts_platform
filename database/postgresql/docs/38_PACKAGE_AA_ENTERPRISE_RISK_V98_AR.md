# الحزمة AA — إدارة المخاطر المؤسسية V98

تنشئ الحزمة سجلًا موحدًا للمخاطر الاستراتيجية والتشغيلية والمالية والقانونية والسيبرانية والخصوصية والسمعة والموردين والاستمرارية والمشاريع. لكل خطر مالك مسؤول وطرف مساءل مستقل، وشهية خطر محددة، ودورة حالة قابلة للتدقيق.

تحتفظ التقييمات المتعاقبة بدرجات الاحتمال والأثر والسرعة وبالأدلة والافتراضات، وتفصل المقيم عن المعتمد. وترتبط المخاطر بضوابط الحزمة Z مع وزن فاعلية مبرر، وبخطط معالجة ومؤشرات إنذار قابلة للقياس.

لا يُغلق الخطر لمجرد اكتمال النشاط؛ يلزم دليل إكمال وتحقق مستقل من فاعلية المعالجة. كما لا تعتبر المخاطر العالية تحت السيطرة دون ضوابط مرتبطة، ولا تستبدل الدرجة المحسوبة حكم الجهة المخولة.

## مخرجات الحزمة

- سجل مخاطر مؤسسي موحد.
- تقييمات أصلية ومتبقية ومستهدفة بإصدارات زمنية.
- ربط المخاطر بالضوابط ووزن فاعليتها.
- خطط معالجة مع تحقق مستقل.
- مؤشرات مخاطر رئيسية وحدود إنذار.
- منظور لحالة المخاطر وفجوات التحكم والمعالجة.
- تراجع آمن يرفض إزالة أدلة المخاطر المحكومة.
