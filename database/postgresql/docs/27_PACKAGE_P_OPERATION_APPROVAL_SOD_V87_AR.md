# الحزمة P — الموافقات التشغيلية وفصل الواجبات V87

الإيقاف المخطط ورفع نسبة التفعيل يمران بمبدأ «العينين الأربع»: ينشئ المدير الأول طلبًا مسببًا بعد تحقق إضافي، ثم يعتمد مدير منصة ثانٍ مستقل أو يرفضه خلال 30 دقيقة. يمنع مشغل قاعدة البيانات مقدم الطلب من اعتماد طلبه، ويرفض الطلب المنتهي أو المحسوم سابقًا.

يبقى تقييم النافذة والإيقاف الطارئ قابلين للتنفيذ الفوري لأن تأخير إجراء السلامة قد يزيد المخاطر. أما الترقية فلا تنفذ من توصية آلية، بل بعد قرار مستقل مسجل بالهوية والوقت والسبب والنتيجة.

ضمانات القبول: منع التكرار، منع الاعتماد الذاتي، انتهاء الموافقة، منع التنفيذ مرتين، والتحقق من دور المدير داخل PostgreSQL لا في الواجهة فقط.
